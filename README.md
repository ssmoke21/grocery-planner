# 🛒 Grocery Planner

A mobile-friendly grocery planning app for families. Plan your weekly list, then switch to shopping mode at the store.

## Features
- **Plan Mode**: Toggle staples on/off, set quantities, add custom items
- **Shop Mode**: Check items off as you go, organized by store section
- **Real-time sync**: Both phones see the same list via Supabase
- **Habit tracking**: Saves shopping history each week

## Tech Stack
- React + Vite
- Supabase (database + real-time)
- Deployed on Vercel
